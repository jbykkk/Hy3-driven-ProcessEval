# Process Evaluator有效性验证结果

## 1. Validation Protocol

有效性验证使用两组用途不同的样本：

| 验证数据 | 数量 | 用途 |
| --- | ---: | --- |
| 人工受控错误样本 | 16 | 验证错误检出、首错定位和错误类型分类 |
| low自然Solver解答 | 45 | 在最终答案全部正确且完成人工过程复核的样本上检查误报 |

受控错误样本用于提供明确的错误位置和类型标签；自然样本用于核验Evaluator是否会对答案正确的自然解答错误报警。两组样本不混合计算总体准确率。

## 2. Error Localization Validation

主要有效性结果采用high Evaluator对16个受控错误样本的评估结果。

| 指标 | 结果 |
| --- | ---: |
| 错误检出率 | 16/16（100%） |
| **首错定位准确率（exact match）** | **16/16（100%）** |
| 错误类型准确率 | 14/16（87.5%） |
| 答案—过程关系识别 | 16/16（100%） |

任务书要求的首错定位准确率在当前受控验证集中为16/16。两例类型错误属于相邻错误类别之间的混淆，不影响这两例的错误检出和首错位置判断。

## 3. False-positive Validation

45个自然Solver解答的最终答案全部正确，并已完成人工过程复核。人工标签与Evaluator判断如下：

| 人工过程标签 / Evaluator判断 | Evaluator有效 | Evaluator报错 |
| --- | ---: | ---: |
| 人工有效 | 44 | 0 |
| 人工无效 | 0 | 1 |

Evaluator在45个最终答案正确样本中仅标记1个过程问题，人工复核确认该样本确实存在过程错误，因此观察到的误报记录为0。

本次45个答案正确样本中未观察到人工确认的误报，但由于异常样本数量较少，该结果只描述当前验证集表现，不作为总体误报率保证。

## 4. Manual Review Record

- 45个自然解答均已完成人工过程复核：44个过程有效，1个过程无效。
- 唯一被Evaluator标记的样本为`math-test-precalculus-0488`。
- 该样本Step 7存在符号计算不一致，后续步骤未给出有效转换。
- Solver最终答案仍然正确，因此该样本属于“答案正确但过程错误”。
- 人工复核确认Evaluator对该样本的报错和首错位置判断均正确。

完整人工标签保存在`experiments/process_evaluator_low_natural_45/human_review.json`。

## 5. Validation Summary

- 当前16个受控错误样本的错误检出率和首错定位准确率均为16/16。
- 错误类型准确率为14/16，答案—过程关系识别为16/16。
- 当前45个最终答案正确的自然样本中未观察到人工确认的误报。
- 当前验证样本规模有限，以上结果证明的是Evaluator在本次实验范围内的有效性，不构成总体统计保证。
