# 完整结果

## 1. Evaluation Setup

主实验使用45道MATH纯文字题，Level 1–5分别包含5、5、5、15、15题。Solver为每道题生成完整的可见解题过程和最终答案；最终答案由独立答案验证器判断，可见过程由人工逐题复核并给出过程正确性标签。正文的最终答案与过程指标均来自low推理条件下的45份自然解答。

## 2. Overall Solver Results

以下指标均针对45道low自然Solver解答计算，不包含人工注入错误样本。

| 指标 | 结果 |
| --- | ---: |
| 样本数 | 45 |
| 完整生成率 | 45/45（100%） |
| 最终答案准确率 | 45/45（100%） |
| 人工确认的过程正确率 | 44/45（97.8%） |
| 答案正确且过程正确 | 44/45 |
| 答案正确但过程错误 | 1/45 |

最终答案准确率和过程正确率是两个独立指标。唯一过程错误样本虽然给出了正确答案，但可见推导中存在计算不一致。

作为资源使用补充，同题high和low Solver均完成45/45题且最终答案45/45正确；low的total tokens为113,594，high为311,089。该对照仅描述当前45题的单次生成结果。

## 3. Difficulty-stratified Results

| MATH难度 | 样本数 | low最终答案准确率 | low人工过程正确率 |
| --- | ---: | ---: | ---: |
| Level 1 | 5 | 5/5 | 5/5 |
| Level 2 | 5 | 5/5 | 5/5 |
| Level 3 | 5 | 5/5 | 5/5 |
| Level 4 | 15 | 15/15 | 15/15 |
| Level 5 | 15 | 15/15 | 14/15 |
| 合计 | 45 | 45/45 | 44/45 |

当前样本中，Level 1–4未观察到最终答案或过程错误，Level 5出现1例过程错误。当前样本未观察到明确的答案准确率下降区间，也不足以确定稳定的难度临界点。

在这组题目上，Hy3的high和low推理均未出现较多错误，暂未观察到由这两个推理强度引起的明显性能衰退。本项目没有继续采用更低的`no_think`条件，是因为该条件不会保留较充分的推理展开，难以稳定提供过程评估所需的完整可见解题过程。

## 4. Error Types

自然45题中仅发现1个真实过程错误，类型为`calculation_error`。该错误数量不足以估计Hy3自然产生各类错误的频率；在当前样本范围内，Hy3基本能够完成这些题目的解答，因此也难以收集到自然产生的多种错误。为继续验证Evaluator的错误识别和分类能力，项目另行构造了人工受控错误样本。

### Controlled Error Coverage

受控实验包含16个错误样本，覆盖8种预定义错误类型：

| 错误类型 | 案例数 |
| --- | ---: |
| `concept_or_theorem_error` | 4 |
| `condition_omission` | 3 |
| `calculation_error` | 2 |
| `case_omission` | 2 |
| `invalid_derivation` | 2 |
| `problem_misinterpretation` | 1 |
| `insufficient_justification` | 1 |
| `answer_extraction_or_format_error` | 1 |
| 合计 | 16 |

该分布是实验设计中的人为覆盖分布，用于Evaluator有效性验证，不代表Solver自然产生各类错误的频率。16例受控错误不与45道自然Solver解答混合计算总体错误率。

## 5. Summary

- 当前45道自然样本的最终答案准确率为45/45（100%）。
- 人工确认的过程正确率为44/45（97.8%）。
- 发现1例答案正确但过程错误的自然样本，说明过程评估具有独立于最终答案验证的价值。
- 当前样本没有显示明确的答案准确率下降区间，也不足以确定稳定的难度临界点。
