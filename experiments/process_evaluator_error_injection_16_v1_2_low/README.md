# 受控错误16例：新版Evaluator low推理对照

本实验冻结v1.2 high实验的16份人工注入错误可见解答、人工标签、Local v1.1、Global v1.2、schema、temperature、top-p、token上限与调用流程，只将Evaluator的`reasoning_effort`从high改为low。

首轮有2个目标评估不完整，随后使用完全相同配置显式恢复；最终16/16均有完整记录。共保存104次成功且完整的API响应。low结果为错误检出13/16、首错14/16、类型14/16、`needs_review` 3/16；high v1.2对应为16/16、16/16、14/16、1/16。

三项主要退化为：一例关键依据不足被聚合为不确定；一例复数分支遗漏发生Local/Global阶段冲突并聚合为不确定；一例错误指数规则被完全判为有效。错误类型总命中数保持14/16，但命中和失败案例发生变化，不能只看总数。

low使用290,652 total tokens、76,315 reasoning tokens；high使用353,599与134,182。由于两轮显式恢复产生的成功调用数不同（104与106），总运行成本和每调用成本均需同时报告，不能把总tokens差异全部视为固定调用数下的节省。
