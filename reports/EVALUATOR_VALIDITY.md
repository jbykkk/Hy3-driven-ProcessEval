# Process Evaluator 有效性验证报告

## 1. 验证方案

| 验证集 | 数量 | 验证目标 |
| --- | ---: | --- |
| 受控错误验证集 | 16 | 错误检出、首错定位和错误类型分类 |
| 常规解答验证集 | 45 | 误报情况及过程判定可靠性 |

受控错误验证集包含16例预设错误位置和类型的解题过程，用于提供明确的人工参考标签；常规解答验证集包含45份未经错误注入的Solver输出，并通过逐题人工复核建立过程正确性参考标签。两个验证集承担不同验证目标，各项指标分别统计。

## 2. 错误检出、定位与分类验证

在同一16例受控错误验证集上，分别使用high和low `reasoning_effort`运行Process Evaluator。两组实验固定解题过程、Step划分、人工参考标签、评估prompt、输出格式及生成参数，仅改变Evaluator推理强度，因此结果可以直接比较。high配置作为本项目Evaluator有效性验证的主要结果，low配置用于观察降低推理强度后的评估表现和资源开销变化。

- 错误检出率统计Evaluator是否识别出过程存在实质性错误；
- 首错定位准确率以人工标注的最早主要错误步骤为参考，采用Step级exact match计算；
- 错误类型准确率统计Evaluator输出类别与人工参考标签完全一致的比例。

| 指标 | high | low |
| --- | ---: | ---: |
| 错误检出率 | 16/16（100%） | 13/16（81.3%） |
| 首错定位准确率 | 16/16（100%） | 14/16（87.5%） |
| 错误类型准确率 | 14/16（87.5%） | 14/16（87.5%） |
| 整体过程判定一致率 | 16/16（100%） | 13/16（81.3%） |
| Reasoning tokens | 134,182 | 76,315 |
| Total tokens | 353,599 | 290,652 |

high配置在16例受控错误中全部正确检出过程问题并定位至人工标注的首个主要错误步骤，错误类型分类有14例与人工参考标签一致。两例分类差异属于相邻错误类别之间的混淆，不影响错误检出和首错位置判断。

各指标依据对应评估字段独立统计。部分样本虽然未形成确定性的整体过程判定，即未将整份解题过程明确判定为错误，但仍给出了与人工参考标签一致的错误位置或类型，因此首错定位和错误类型的正确数量可能高于整体错误检出数量。

与high相比，low配置的Reasoning tokens减少43.1%，Total tokens减少17.8%，但错误检出率由100%降至81.3%，首错定位准确率由100%降至87.5%。因此，本项目采用high配置作为Evaluator有效性验证的主要结果，low配置用于反映推理开销与评估表现之间的权衡。

## 3. 误报验证与人工复核

误报验证使用low Evaluator对45份常规解答验证集的评估结果。该验证集中的45份解答最终答案均正确。为建立完整的过程正确性参考标签，全部样本均经过逐题人工复核，并与Evaluator判定逐条比较。

| 核验指标 | 结果 |
| --- | ---: |
| 最终答案正确的常规解答 | 45 |
| Evaluator判定过程存在问题 | 1 |
| 人工复核确认存在过程问题 | 1/1 |
| 人工复核确认误报 | 0/1 |

| 人工参考标签 / Evaluator判断 | Evaluator判定过程正确 | Evaluator判定过程存在问题 |
| --- | ---: | ---: |
| 人工复核过程正确 | 44 | 0 |
| 人工复核过程存在错误 | 0 | 1 |

唯一被判定存在过程问题的样本为`math-test-precalculus-0488`。人工复核确认其Step 7存在代数变换符号不一致，且后续推导未给出有效修正；尽管最终答案正确，该可见过程本身存在实质性错误。因此，该判定不属于误报，Evaluator给出的首错位置也与人工复核一致。

完整逐题人工参考标签见`experiments/process_evaluator_low_natural_45/human_review.json`。

## 4. 验证结论

在16例受控错误验证集上，high Process Evaluator实现100%的错误检出率和首错定位准确率，错误类型准确率为87.5%。low配置虽然降低了推理token开销，但错误检出和首错定位指标出现下降，因此high作为当前Evaluator的主要验证配置。

在45份常规解答验证集中，Evaluator判定的唯一过程问题经人工逐题复核确认属实，其余44份过程正确样本均未被错误判定，当前验证集未观察到误报。受限于验证集规模，上述结果用于说明本项目Process Evaluator在当前实验范围内具备过程错误识别、首错定位和过程有效性判定能力，不进一步外推至其他数据分布。
